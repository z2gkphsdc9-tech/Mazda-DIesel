1. Подготовка — что нужно иметь

  1. USB-флешка
    Объём 4–16 ГБ (лучше не больше 32 ГБ). Отформатировать в FAT32, размер кластера — по умолчанию. Флешка должна быть пустой.
  2. Компьютер с Windows / macOS / Linux.
  3. Программа MZD-AIO-TI (скачать с mazdatweaks.com или GitHub Trevelopment/MZD-AIO). Актуальная версия ≈ 2.8.6.
  4. Для прошивок 70 и 74 дополнительно:
    • USB-клавиатура (обычная проводная)
    • Смартфон или ноутбук с Bluetooth (для 74)
    • Файлы разблокировки (папка XX / 74.sh — брать из проверенных архивов сообщества)
  5. Заряженный аккумулятор или работающий двигатель. Нельзя, чтобы машина ушла в сон во время процесса.

2. Как узнать версию прошивки

  1. Включите зажигание (ACC или двигатель).
  2. На экране ГУ зайдите: Настройки → Система → Информация о версии (или System → Version Information).
  3. Запишите строку вида 74.00.324A-EU или 70.00.100 / 59.00.502 и т.д.
  4. От этой версии зависит, какой способ разблокировки использовать.
Кратко по версиям:
• до 59.00.502 — твики ставятся просто
• 59.00.502 – 70.xx — нужна подготовка (SSH / ID7)
• 74.xx — нужна специальная разблокировка (см. раздел 6)

3. Установка программы MZD-AIO-TI

  1. Скачайте установщик с сайта mazdatweaks.com (или с GitHub Releases).
  2. Установите программу на компьютер.
  3. Важно: перед первым запуском некоторые пользователи рекомендуют отключить интернет на компьютере, потом можно включить обратно.
  4. Запустите MZD-AIO-TI. Должен открыться интерфейс с списком твиков.

4. Обновление прошивки (краткая схема)

  1. Скачайте нужную прошивку своего региона (EU / NA и т.д.).
  2. Отформатируйте флешку в FAT32.
  3. Скопируйте файлы прошивки в корень флешки (не в папку).
  4. В машине: зажигание ACC или двигатель заведён. Вставьте флешку.
  5. Путь: Настройки → Система → Обновление системы.
  6. Дождитесь окончания (обычно 30–50 минут). Не выключайте питание.
  7. После обновления проверьте версию (раздел 2).
Если у вас очень старая прошивка (29–30), обновляйтесь поэтапно: сначала 31.00.100 → потом 56/59 → потом 70/74.

5. Разблокировка на прошивке 70.xx

На 70+ штатный autorun с флешки заблокирован. Нужно вернуть возможность ставить твики.

Вариант A — через ID7 Recovery (рекомендуемый)

  1. Откройте MZD-AIO-TI.
  2. Включите опцию Autorun & Recovery + галочку ID7 Recovery Scripts Pack (и при необходимости Recovery Via Serial Connection).
  3. Нажмите Start Compilation и запишите на чистую FAT32-флешку.
  4. Вставьте флешку в машину, дождитесь окна установки, подтвердите.
  5. После успешной установки можно обновляться на 70.00.100 (не выше, если хотите сохранить простой способ установки твиков) или ставить твики.

Вариант B — через serial (USB-UART)

  1. Купите USB-to-UART адаптер + пины (терминалы 8240-0215 или аналоги).
  2. Разберите панель, подключите адаптер к разъёму ГУ (по схемам с Drive2 / форумов).
  3. Подключите к ноутбуку, откройте терминал (PuTTY / screen) на нужном COM-порту.
  4. Во время обновления прошивки или в нужный момент выполните команду копирования autorun (пример из отчётов):
cp -r /mnt/sd*/XX/* /mnt/data_persist/dev/bin/; chmod +x /mnt/data_persist/dev/bin/autorun; /mnt/data_persist/dev/bin/autorun

Точные команды и момент ввода зависят от конкретной инструкции, которую вы используете. Делайте строго по проверенному гайду.

6. Разблокировка на прошивке 74.xx (пошагово)

Работает стабильнее всего на 74.00.311 и 74.00.324. На 74.00.331+ после твиков бывают проблемы с wireless CarPlay.

Что подготовить

  1. USB-флешка FAT32 с файлами разблокировки: 74.sh + папка XX_74 (или аналог из проверенного архива).
  2. Обычная USB-клавиатура.
  3. Смартфон или ноутбук с Bluetooth.
  4. Специальный MP3-файл для входа в диагностику (лежит в тех же архивах сообщества / GitHub mzd-evo).

Пошаговая разблокировка

  1. Подключите Bluetooth
    Соедините телефон/ноутбук с ГУ по Bluetooth. Воспроизведите специальный MP3-файл. Должно появиться диагностическое / Test Screen окно.
  2. Вставьте USB-клавиатуру в свободный USB-порт машины.
  3. В диагностическом меню введите код (часто 11) и нажмите Enter. Дальше действуйте по вашей конкретной инструкции (могут быть дополнительные коды).
  4. Откройте терминал (появляются строки ввода команд).
  5. Вставьте флешку с файлами разблокировки (если ещё не вставлена).
  6. Выполните команды по очереди (пример из рабочих отчётов): 
    ls
cd /tmp/mnt/sda1
# или sdb1 / sdc1 — смотрите вывод ls
ls
sh 74.sh
    Дождитесь окончания (может появиться Complete или просто новые строки).
  7. Выйдите из диагностики, перезагрузите ГУ (см. раздел «Перезагрузка»).
  8. Теперь ГУ готово к установке твиков. Переходите к следующему разделу.
Если после разблокировки «отвалилась» шайба (командир) — сделайте hard-reboot: зажмите Music + Navi + Mute на 10–20 секунд.

7. Установка твиков через AIO (после разблокировки)

  1. Откройте MZD-AIO-TI на компьютере.
  2. Отметьте нужные твики зелёными галочками (установка). Красные — удаление.
  3. Обязательно поставьте в начале:
    • Backup JCI Folder
    • Install SSH_bringback (если ещё не стоит)
  4. Нажмите Start Compilation.
  5. Запишите результат на чистую FAT32-флешку (или скопируйте содержимое папки «copy to usb»).
  6. Для прошивки 74 обязательно:
    Откройте на флешке файл tweaks.sh или run.sh блокнотом.
    Найдите строку -eq 70 и замените на -eq 74. Сохраните.
  7. В машине: только эта флешка, зажигание ACC / старт. Вставьте флешку.
  8. Через 10–40 секунд должно появиться окно MZD-AIO-TI. Нажмите YES / Продолжить.
  9. Дождитесь окончания всех окон. В конце обычно предлагают перезагрузку.
  10. Вытащите флешку и перезагрузите ГУ.

8. Установка конкретных популярных твиков

8.1 Тачскрин во время движения (Touchscreen While Moving)

  1. В AIO поставьте галочку Touchscreen While Moving.
  2. Соберите пакет (Start Compilation) и запишите на флешку.
  3. Для 74 — замените -eq 70 на -eq 74.
  4. Установите в машине как в разделе 7.
  5. После перезагрузки тачскрин должен работать на ходу.

8.2 Убрать предупреждение при запуске (No More Disclaimer)

  1. В AIO отметьте No More Disclaimer.
  2. Выберите вариант (полностью убрать / сократить время показа).
  3. Соберите → флешка → установка → перезагрузка.

8.3 Убрать надпись на камере заднего вида

  1. Отметьте Reverse Camera Safety Warning.
  2. Соберите пакет и установите.
  3. После установки при включении задней передачи предупреждение внизу экрана должно пропасть.

8.4 Свой фон главного экрана (Background Image)

  1. Подготовьте картинку (желательно 800×480, PNG или JPG).
  2. В AIO отметьте Background Image и укажите свою картинку (или выберите из предложенных).
  3. Соберите → установите → перезагрузите.

8.5 Цифровой спидометр (Speedometer)

  1. Отметьте Speedometer.
  2. При желании настройте, какие данные показывать (скорость, температура ОЖ, GPS-скорость и т.д.).
  3. Соберите и установите.
  4. После установки спидометр появится в списке приложений главного меню.

8.6 Видеоплеер

  1. Отметьте Videoplayer.
  2. Рекомендуется вместе со Swapfile (дополнительная память с флешки) — тогда видео работает стабильнее.
  3. Установите. Видеоплеер появится в приложениях. Видео кладёте на ту же или другую USB-флешку.

8.7 Дата в статусбаре + доп. информация

  1. Отметьте Statusbar Tweaks и/или Date in Statusbar.
  2. Выберите формат даты и нужные иконки.
  3. Установите и перезагрузите.

8.8 SSH (удалённый доступ)

  1. Отметьте Install SSH_bringback.
  2. Установите.
  3. После установки данные для входа обычно: пользователь cmu / пароль jci (или root/jci на более старых).

8.9 Несколько твиков сразу

  1. Отметьте все нужные галочки в одном запуске AIO.
  2. Сначала всегда ставьте Backup + SSH_bringback.
  3. Не ставьте сразу 15–20 твиков, если делаете первый раз — лучше порциями.
  4. Соберите один пакет → установите → проверьте → при необходимости добавьте ещё.

9. Удаление твиков

  1. Откройте MZD-AIO-TI.
  2. Отметьте нужные твики красными галочками (Uninstall).
  3. Соберите пакет и установите так же, как при установке.
  4. После удаления сделайте перезагрузку ГУ.
  5. Не делайте «Сброс к заводским настройкам» ГУ, пока твики не удалены через AIO — можно получить проблемы.

10. Как перезагрузить ГУ

  • Обычный способ: зажать NAV + MUTE (или Music + Navi + Mute) на 10–20 секунд до перезагрузки.
  • Иногда помогает просто выключить зажигание на 1–2 минуты и включить снова.
  • Hard reboot после некоторых операций обязателен.

11. Риски и что делать при проблемах

  • Можно получить «кирпич» или бесконечную перезагрузку (bootloop).
  • На части 74.00.331+ после AIO пропадает wireless CarPlay.
  • Гарантия на ГУ может быть потеряна.

Если что-то пошло не так

  1. Сделайте hard-reboot (NAV + MUTE / Music + Navi + Mute).
  2. Попробуйте установить пакет удаления твиков (красные галочки).
  3. Если ГУ не загружается — ищите инструкции по fail-safe / перепрошивке через программатор (CH341A) или обращайтесь к тем, кто уже восстанавливал такие ГУ.
  4. Всегда держите бэкап (Backup JCI), который делали в начале.
Главное правило: делайте всё спокойно, по одному этапу, с бэкапом. Не торопитесь и не отключайте питание во время записи.
